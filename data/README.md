# Country names

`countries.tsv` contains ISO 3166-1 alpha-2 codes and English names extracted
from iso-codes 4.20.1 (`/usr/share/iso-codes/json/iso_3166-1.json`).
Source: https://salsa.debian.org/iso-codes-team/iso-codes
